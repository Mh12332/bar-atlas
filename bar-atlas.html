FOUNDATIONS / 底层

一杯酒成立的四个变量

配方会变，结构不会。先判断这杯酒在解决什么问题，再决定放多少、怎么冷、用什么杯。

01

结构 Structure

基酒提供骨架，酸提供明亮度，甜负责回甘，稀释把三者融合，香气给出方向。任何一杯经典都能拆成这五件事。

先问：这杯酒的「骨架」是什么？

02

平衡 Balance

平衡不是甜酸相等，而是让每一口都有开头、中段和收尾。酒体越重，越需要酸或苦把结尾收干净。

先修结构，再修风味。

03

稀释 Dilution

水是配方的一部分。搅拌带入 15–20%，摇和带入 20–25%，冰沙更多。稀释不足会烈，过度会散。

冰的大小，就是稀释的速度。

04

温度 Temperature

温度是隐形的调味料。杯子、酒液、冰块、出品速度，每一项都在改变香气释放与口感。冰杯不是礼貌，是配方。

一杯酒的寿命，常常只有 10 分钟。

02 / ARCHITECTURE

从配方，回到可分析的模型

DERIVATION TREE / 架构演化树

改一个变量，还是换一个骨架？

不是按名字背家族，而是看“从哪来、改了哪一步、结果是否还是同一结构”。箭头上的操作比终点名字更重要。

1 次操作 · 换主体同骨架，换表达

Daiquiri → Gimlet / Margarita：酸甜结构不变，只是主体换了。

1 次操作 · 换甜或换酸同骨架，开新枝

Whiskey Sour → Gold Rush：糖换蜂蜜；Sidecar 是糖换橙味利口。

1 次操作 · 加稀释同骨架，变长饮

Sour → Collins：加苏打；Sour → French 75：把气泡换成起泡酒。

2 次以上核心操作新骨架

Sour 去酸再加苦精 → Old Fashioned：不能算酸酒变体，而是回到古典骨架。

01 / MAIN

主酒

有独立名称、历史与完整配方，可以单独被点单。例如 Negroni、Boulevardier、Old Pal 各自都是主酒。

02 / VARIANT

变体

只改母配方的一个变量：基酒、酸、甜、质地、温度或气泡。变体不另立门户，挂在母配方下。

03 / FAMILY

家族 / 谱系

共享结构或历史的多个主酒。关系图用“同族变体 / 历史谱系”连接，而不是把独立酒款塞进变体列表。

VARIATION LOGIC / 变体

变体不是新配方，
是换一个变量。

掌握五种改法，就能从一杯酒推导出一个家族。独立命名的酒款另立主酒，不与母配方重复。

01

换基酒

Daiquiri → Caipirinha / Mojito。结构不变，甘蔗的香气方向变了。

02

换酸

Whiskey Sour → Gold Rush。柠檬换成蜂蜜的圆润，酸度仍在。

03

换甜

Daiquiri → Hemingway。糖减少，黑樱桃与西柚补上苦甜。

04

换质地

Sour → Fizz / Flip。加气泡变轻，加蛋奶变厚。

05

换温度

Margarita → Frozen Margarita。冰沙改变稀释、甜感与饮用速度。

BOTTLE GUIDE / 酒款速查

同一类酒，品牌决定方向

32 类常见酒款按 9 个家族整理：先认清这是什么风格，再看它适合做哪些酒、换一瓶会怎样，最后才决定买哪一瓶。品牌只是类别示例，不是采购推荐。

风格酒精度常用瓶拿它做什么一句话

没有匹配的酒款，试试减少一个条件，或只搜品牌名的前两个字。

品牌与可得性会因国家和年份变化；价格档位只是「日常 / 进阶 / 高价」的相对刻度，不是具体售价。本表用于建立“类别—风格—用途”的对应关系，而不是采购清单。

MATERIAL INDEX / 材料小词典

每种材料，先知道它为什么在这里

从全部配方反推、去重后的材料索引；按类别、使用频次排序，并保留每种材料的一句定位。

类别材料一句话常见用途品牌 / 备注

RULE 01

先减糖，再加酸。

利口酒、果汁、味美思都带糖。配方里的糖浆不是固定值，先看其他材料的甜度。

RULE 02

苦味只差几毫升。

Campari、Fernet、Suze 的性格极强。5 ml 足以改变一杯酒的方向，别用「差不多」计量。

RULE 03

同一类不能盲换。

Cointreau 与 Triple Sec 的甜度、酒精度不同；干味美思与 Lillet 也不是等量替代。先试再换。

06 / TECHNIQUE

动作决定口感，
冰决定时间。

摇和、搅拌、直调、捣压、搅打、干摇、滚动。每一种动作都在改变温度、稀释与质地。

ICE / 冰

冰是配方的一部分

冰的形状决定融化速度，融化速度决定稀释。不要用「越多越好」或「越冷越好」概括它。

大冰块2.5–5 cm

融化慢，适合古典、搅拌类短饮。杯中最稳。

长冰 / 高球冰2 × 10 cm

表面积小、降温快，适合高球，保留气泡。

碎冰不规则

快速稀释与降温，适合 Tiki、Julep、冰沙。

摇壶冰2–3 cm

摇和用，冰量占壶 2/3；太小会过度稀释。

DILUTION / 稀释

水从哪里来

一杯 90 ml 的搅拌短饮，可能含有 15–20 ml 的融水。稀释不是失误，是配方设计。

BAR SCIENCE / 吧台科学

配方之外，六个真正影响味道的变量

这些不是“秘诀”，而是可以量化、可以复盘的变量。先控制它们，再谈创意。

BALANCE / 诊断

不好喝时，先改哪一个变量？

按顺序检查：温度 → 稀释 → 酸甜 → 苦香 → 质地。不要一上来就加糖。

症状常见原因怎么修下次怎么防

PREP / 预制

糖浆是厨房里的配方

同一杯酒，用不同浓度与糖源的糖浆，甜感、质地与香气都会变。以下是吧台最常用的七种。

BATCH / 批量

提前做，不等于提前加水

  • 01先算总容量，再按比例放大；糖浆与柑橘最后加。
  • 02提前冷藏到 2–4°C，减少现场冰的稀释。
  • 03批量时只预加 10–15% 水，剩余稀释留给杯中冰。
  • 04含蛋、奶油、气泡的配方不适合长期批量。
  • 05每批出品前都要试味，不是只看配方。

STORAGE / 保存

开瓶之后，风味开始倒计时

  • 味美思冷藏，开瓶后 4–6 周；用真空塞可延长。
  • 鲜榨柑橘冷藏 24 小时；青柠可 48 小时，但香气会下降。
  • 糖浆冷藏 2–4 周；出现气泡或酸味立即丢弃。
  • 蛋 / 奶油全程冷藏，蛋清当天用完；奶油不反复回温。
  • 苦精 / 烈酒常温避光；高酒精度不易坏，但香气会衰减。

GLASSWARE / 杯具

杯子是配方的一部分

杯型决定香气聚拢、冰的容量、手持温度与饮用速度。先冰杯，再谈装饰。

A NOTE ON RECIPES

配方是坐标，不是法律。

同一杯古典鸡尾酒，在不同年代、城市与调酒师手里会有不同的糖量、苦精与搅拌时间。这里给出的是可复现的起点：先按比例做，再用舌头、冰块与客人的偏好调整。所有含酒精饮品请适量；无酒精配方中的苦精可能含酒精，为孕妇、儿童或完全禁酒者制作时请确认。
